# Who-Dares-Awaken-Me...
Awaken inside a graveyard... which is under the attack of pumpkins!

Defend and fix all the tombstones!

Features 2D characters that change sprite based on camera direction in 3D space.

Play now in browser on itch.io!\
https://andeeeeez.itch.io/who-dares-awaken-me

Made in 48 hours for November 2025 Halloween RPI Game Dev Club Game Jam\
